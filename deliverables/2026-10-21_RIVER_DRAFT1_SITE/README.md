## 1 旋转楼梯（`PROGRAM::Stair`，名称 SPIRAL STAIR）
楼板上 4 个 r = 15' 的圆形开洞，(613, 326)、(237, 138)、(69, 147)、(381, 392)，都是 L2 → L3（20' → 36'）。每处放一部 Ø12' 旋转楼梯：24 级踏步（每级 0.67'）、转 330°、中心立柱。楼梯贴开洞边缘，顶层踏步朝向楼板中部的落脚处。

## 2 花园和露台（greens 图层上已命名的 GARDEN / TERRACE / GREEN ROOF）
设计语言按你们的参考（一系列 fillet 线，Vancouver WA / Seattle 滨水的尺度）：
- **带状系统**：每块绿地沿自身的脊线排出一组平行带，带的曲率跟随脊线。各条带在靠近建筑 / 入口的一端收束到同一个点，另一端统一截在一条直线上，没有圆头。
- **带的内容**：
  - 花园：10' 步道（GARDEN WALK）+ 7' 木质座阶（SEATING STEPS）。
  - 露台：木质平台带（TERRACE），平台之间是抬高的种植池。
  - 绿屋面：屋面步道（ROOF WALK）+ 座阶。
  - 坡地花园：带沿等高线排布，即台阶式看台。
- **其它**：
  - 收束点一带铺深色铺装（`PAVING INLAY`）。
  - 带之间是种植，隔一条种植带种一排树（间距约 30'）。
  - 平台和步道边放长条座椅，座阶上画两道台阶线。
  - 带上散布人物。
- **改动方式**：greens 物件按带切开，保留原图层和名称（露台的种植池不命名，避免重复标字）。原物件和它们的 2D 轮廓线移到 LEFTOVERS。
- **新图层**：`PROJECT SITE::GARDENS::*`，包括 PATH / SEATING / DECK / PAVING INLAY / FURNITURE / TREES / PEOPLE。

## 3 PROJECT SITE（按最新的 greens 和 road 重新设计）
- **滨水公园**（`RIVERFRONT PARK`）整体重画，采用同一套带状语言：
  - 沿河：木栈道（BOARDWALK）、22' 宽 RIVER WALK（沿内侧每 42' 一条 14' 长凳）、种植带加行道树。
  - 中间：三段"叶形"带组。每组是步道 + 木质座阶 + 草坪，中段在草坪前加一条雨水花园。
  - 节点：两条横向步道（CROSS WALK，深色铺装，直线）。带组在这两处收束成点，并统一截在直线上。
  - 沿建筑一侧：上层步道（UPPER WALK）。
  - 节点旁两座亭子，第一处节点旁一块戏水场地（WATER PLAY）。
  - 保留亲水台阶和皮划艇码头，其余地面为草甸。
  - 你们的 greens 和上面设计的花园都保留，所有带都绕开它们。
- **地块内其余地面**（`PROJECT SITE::PLAZA`）按位置分区并命名：LOADING（4 个卸货车位）、SECONDARY DROP OFF PLAZA（自行车架）、ACCESS TO RIVER WALK、SOUTH WALK、EAST WALK、AUDITORIUM FORECOURT。另有行道树和长凳。原来的 PLAZA 铺装移到 LEFTOVERS。
