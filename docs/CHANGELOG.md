# 修订记录（PRD v0.5 之后）

按时间倒序。每条：版本 · 用户反馈 → 做了什么。细节以 PRD v0.7 正文为准。

| 版本 | 用户反馈 / 起因 | 结果 |
|---|---|---|
| v0.4.0 | S4；色块缝里透出看线；插件要全英文；输出放模型旁、不自动打开 AI；剖切和立面分开 | 新增 Plan（每层画板 + 总排版、MIC 标签/引线、图例、比例尺、指北针、背景、玻璃线、通高虚线）和 Axon 叠合式 / 爆炸式；剖面色块下铺白底；界面全英文、面板 9 页（6 Sections / 7 Elevations 分开）；每次导出在模型文件夹新建 `YYYY MMDD_Conceptual Program Diagram_HHMMSS`，Illustrator 后台生成后退出 |
| v0.3.2 | 横向剖切 GG 时周边建筑没被切到 | 不封闭的周边建筑多重曲面：先按剖切线闭合截面；仍不行就按看线画，不再整栋消失 |
| v0.3.1 | AI 里出现灰色旧剪影；立面类型下拉跳回 Section | 重新导出时清除旧版本残留的生成图层；看线在地坪处截断；修复 ⑥ 类型下拉 |
| v0.3.0 | 自己楼的看线要像立面（半灰、不透明、Make2D）；新增 Elevation | 新增共用的投影视图：体块浅灰实心底，楼板/各立面图层各自一层一色板，玻璃白色实心，近挡远；新增立面出图（▼ 标高符号、虚线标高线） |
| v0.2.2 | 文字和层高标注消失、楼层线太淡；看线要有遮挡；考虑地下室 | 文字以 1" = 45' 为基准随比例缩放；恢复层高标注列、总高标注、灰色楼层线；剖到的别人楼白底黑线，看到的白底灰虚线、由远到近遮挡；地坪线 = 楼板 2 倍、居中在地坪；地下 program 同地上 |
| v0.2.1 | 参考图：真实比例、楼板加粗、色块与楼板留缝、文字居中；自己的楼和别人的楼画法不同 | 永远真实比例，比例自由输入（Bluebeam 式）+ 预设，画板 Fit content；楼板固定 3 pt 视觉粗细，色块留 2 pt 白缝；标签粗体全大写并按字形居中；可选导出 PNG |
| v0.2.0 | 进入 S3 | Section 输出、Illustrator 自动化（总控 JSX、全局色板、段落样式、命名图层、原位更新、`_MANUAL`/`OVERLAY` 保护）、SVG 预览、COM 启动 |
| v0.1.1 | ⑤ 配色要能自定义 program，并联动图层 | 自定义 program（自动 Key/颜色/别名，可删除）；① 图层和 ④ 单个体块的 program 下拉联动；无 program 的体块显示为 Unassigned |
| v0.1.1 | 跨层改「Single」无效；导出用了旧结果 | Single = 只算底层；改跨层或导出前自动重新分析 |
| v0.1.0 | 公司电脑不能往 Rhino 安装目录放文件 | 插件放在用户文件夹，拖 .rhp 进 Rhino 即可，无需管理员权限 |
| S0–S2 | 初始开发 | 解决方案与测试数据；核心几何（楼层判定、封口、切片、跨层、重叠、面积）；Rhino 面板 ①–⑧、楼层预览、设置存入 3dm |

## Windows 试用已确认
- 插件可从用户文件夹安装运行；T1 图层预填、T3 楼层、T4 面积均通过；Linux 上的 Core 计算结果与 Rhino 导出的 areas.csv 完全一致。
