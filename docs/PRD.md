# PRD：CAD → Program Diagram 生成器（Axon / Section）

v0.2 · 2026-10-09 · 状态：草案（已纳入第一轮反馈）

## 1. 目标
把手工绘制 program diagram 的流程标准化：

> 输入 CAD（2D 平面或剖面）→ 自动识别空间 → 屏幕上确认、修改 → 输出分图层、可继续编辑的 Illustrator 文件

- **功能 A**：多层 2D 平面 → 轴测 program diagram
- **功能 B**：2D 剖面 → section program diagram（含背景建筑）
- **风格基准**：以参考项目（Research Building）的平面、轴测、剖面为默认样式，见第 5 节。

**成功标准**
- 一张图从 DXF 到 AI 用时 ≤ 15 分钟
- ≥ 90% 的空间不需要手动修改就能正确识别
- 输出与参考项目在颜色、字体、线型上一致

## 2. 范围
| 本期做 | 本期不做 |
|---|---|
| DXF 输入（DWG 先用 ODA File Converter 批量转换） | 直接读 Revit / Rhino 模型 |
| 一个 DXF 含多层平面，或多个 DXF，都支持；分层结果由用户确认 | PDF 或图片输入 |
| 自动识别闭合边界和房间名，匹配公司图例 | 流线自动生成（在 AI 中手画） |
| 确认界面：改名、改 program、改颜色、合并、拆分、删除、补画 | 配景自动布置（树、人只放占位） |
| 剖面中的背景建筑，按"剖到 / 未剖到"分两种样式 | 云端协作、多用户 |
| 导出：Illustrator 脚本（生成原生分图层 .ai）和 SVG 预览 | |

## 3. 用户流程
1. **导入**：拖入一个或多个 DXF，选择类型（平面 / 剖面）。
2. **分层**（仅平面）：
   - 系统按外轮廓聚类，并读取图名文字（如 `Level 1`、`PLAN, LEVEL 2`），自动切分出各层并命名；
   - 用户在界面中确认，可框选修改、调整顺序、填写层高，并把各层对齐到同一基准点。
3. **自动识别**：识别边界和房间名，匹配 program，生成预览。
4. **确认**：处理高亮的"不确定项"，调整参数；预览实时刷新。
5. **导出**：下载 `.jsx`，在 Illustrator 中运行（文件 › 脚本），得到 .ai。
   - 回到第 4 步修改后可以重新导出；只更新生成的图层，不动手调图层。

## 4. 功能需求

### F1 平面分层
- 一个 DXF 中的多张平面：
  - 按外轮廓或包围盒聚类成候选楼层；
  - 就近匹配 `Level N` 或 `LEVEL N` 文字，作为层名；
  - 按层名排序。
- 多个 DXF：每个文件作为一个候选楼层，文件名作为默认层名。
- **对齐**：默认用各层外轮廓的左下角对齐；用户可以手动指定一个对齐点，如结构柱或核心筒角点。
- 以上结果都必须由用户在界面中确认后，才能进入下一步。

### F2 边界识别
- 识别来源（按优先级）：
  1. 闭合多段线
  2. 填充（Hatch）边界
  3. 散线：在容差内自动补缝，再用 polygonize 围合成面
- 过滤：小于最小面积的区域、重复区域、墙体内的碎片
- **剖面专用**：
  - 长水平线识别为楼板线，得到楼层；
  - 粗线闭合区域识别为"剖到的建筑"，其余建筑识别为"未剖到的背景建筑"，用户可逐栋切换。

### F3 名称与 Program 匹配
- 区域内的 TEXT / MTEXT 作为空间名。
- 按关键词匹配公司图例（见第 5 节），例如：
  - `HISTOLOGY`、`GENOMICS`、`PROTEOMICS` → Lab
  - `LOCKERS`、`MAIN ELECTRICAL` → Building Support
- 匹配不到时标为 `Unassigned`（灰色），并加入不确定项清单。
- 关键词表可编辑，修改会累积到公司库中。

### F4 不确定项标记
以下情况在界面中黄色高亮，并列出清单，可逐项跳转处理：
- 区域没有文字，或含多个文字
- 补缝后才闭合
- 面积异常
- 区域之间有重叠
- 没有匹配到 program
- 平面分层有歧义

### F5 确认 / 编辑界面
- 画布：平移缩放；点击区域可改名、改 program、改颜色。
- 编辑操作：多选合并、按线拆分、删除、手动补画多边形。
- 参数面板见第 6 节；左右分屏，一侧是识别结果，一侧是生成预览。

### F6 生成器
- **Axon**（风格同参考项目）：
  - 每层外轮廓为白色楼板，黑色粗轮廓，并画出楼板厚度；
  - program 色块铺在楼板顶面；
  - 可选择爆炸式（层间拉开）或叠合式（参考项目中 RECEIVE 那张的样式）；
  - 场地为绿色底，街道为灰色粗箭头加白字。
- **Section**（风格同参考项目的 Section A / B）：
  - 剖到的建筑：黑色粗外轮廓；内部每个空间是圆角色条，空间之间留细白缝，标签居中；
  - 未剖到的背景建筑：浅灰虚线外轮廓和楼层线，不填色，顶部标建筑名；
  - 地坪：灰色地面带；
  - 注释：红色点划线表示用地红线，竖排标注 `PROPERTY LINE`；建筑总高度用斜杠端点标注；街道名放在地坪上方；右上角放 key plan 占位。

### F7 Program 库
- 默认值采用公司现行图例，见第 5.1 节。
- 每类包含：显示名、颜色、文字颜色、关键词。
- 可导出为 `program-library.json`，作为项目或公司模板。

### F8 导出（Illustrator）
- 每个 program 建一个**全局色板**：改一个色板，全图同步。
- 文字可编辑，并套用段落样式。
- 图层结构：
  ```
  _MANUAL / ANNO / LABELS(L1…Ln) / PROGRAM(L1…Ln) / OUTLINE / CONTEXT(BG_BLDG, GROUND, SITE)
  ```
- 对象按 `L3_LAB_01` 这样的规则命名。重新导出时按名字原位更新；`_MANUAL` 图层永不覆盖。

## 6. 待确认参数（界面默认值）
| 参数 | 默认值 |
|---|---|
| 单位 / 比例 | 从 DXF 读取，可改（英制项目用 ft-in） |
| 补缝容差 | 1'-0"（300 mm） |
| 最小面积 | 20 SF |
| 轮廓简化 | 4"（100 mm） |
| 轴测投影 | 30° / 30° 等轴测 |
| 轴测模式 | 爆炸式 / 叠合式 |
| 层间距 | 爆炸式默认 1.5 × 层高 |
| 楼板厚度 | 图面 600 mm |
| 剖面色条内缩 | 0.12 × 层高 |
| 剖面房间合并 | 同 program 且相邻的空间合并为一条：开 / 关 |

## 7. 技术方案
- **核心**：Python（`ezdxf` 读取 DXF，`shapely` 做几何运算），封装为本地服务。
- **界面**：浏览器单页应用（SVG 画布）。全部在本地运行，图纸不上传。
- **导出**：生成 Illustrator ExtendScript（.jsx），把数据以 JSON 形式内嵌，在 AI 中原生绘制。
- **数据**：项目保存为 `project.json`（几何 + program + 参数 + 用户修改记录），可以重新打开继续修改。

## 9. 风险与待定问题
- **CAD 图纸质量是最大风险。** 需要一份最低制图约定：
  - program 区域用闭合线或填充；
  - 房间名放在区域内；
  - 无关图层导出前关闭。
- 需要参考项目的 **AI 原文件**，用来校准精确色值、字体、线宽和段落样式；需要对应的 **DXF**，作为测试样本。
- 剖面中"剖到 / 未剖到"的自动判断依赖线宽或图层；如果 CAD 中没有区分，就默认由用户逐栋指定。
