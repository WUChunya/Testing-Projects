# PRD：Program Diagram Rhino 8 插件

v0.4 · 2026-10-09 · 状态：草案（按第四轮需求重写）

> 一句话：在 Rhino 8 里，把**带命名的 program 体块和背景**，一键生成 Plan、Section、Axon、Program 分类图和饼图，每张图是一个分图层的 .ai 文件，全部输出到同一个文件夹。

---

## 1. 总体流程

| 阶段 | 谁来做 | 内容 |
|---|---|---|
| **A 用户输入** | 用户 | ① 指定哪些图层是背景，以及用什么风格画；② 做好 program 体块并命名 |
| **B 系统生成，用户确认** | 系统 → 用户 | 房间 / 体块 / 图层名称、配色方案、楼层线、剖切线、输出路径 |
| **C 系统自动添加** | 系统 | 配景人物：随机分布，放在独立图层 |
| **D 成果** | 系统 | Plan、Section、Axon（叠合式 / 爆炸式）、Program 分类图、饼图，都是 .ai，输出到同一文件夹 |

插件形态：
- 正式的 Rhino 8 插件（.rhp），通过 Yak / Package Manager 安装，Windows 和 Mac 都支持；
- 带工具栏，主命令是 `ProgramDiagram`，配一个可停靠的侧边面板；
- 所有设置保存在 3dm 文件里，下次打开不用重新配置。

## 2. A — 用户输入

### A1 背景分类与风格
面板第 1 页"图层分类"列出模型中所有**有对象的图层**（隐藏图层默认不勾选）。用户为每个图层指定一个角色：

| 角色 | 举例 |
|---|---|
| `Program` | 由插件读取的 program 体块（见 A2） |
| `BG·Building` | 周边建筑、本项目的其他楼栋 |
| `BG·Road` | 道路 |
| `BG·Hardscape` | 人行道、广场 |
| `BG·Landscape` | 绿地、种植池 |
| `BG·Tree` | 树（可以是图块） |
| `BG·Water` | 水体 |
| `BG·Line` | 用地红线、轴网等线性要素 |
| `Ignore` | 幕墙、竖梃、材质、渲染辅助等 |

每个背景角色选一种**风格模式**，默认值来自公司配色方案：

| 模式 | 效果 |
|---|---|
| **黑白灰** | 灰度填色，加细黑或深灰轮廓 |
| **线型** | 不填色，只画轮廓；可选实线或虚线，可设线宽 |
| **彩色** | 使用公司配色，如绿地 `#D7DEBC`、树 `#C8E2BF` 加深绿轮廓 |

- 同一个角色在不同的图里可以用不同的模式。例如 `BG·Building` 在 Plan 中是灰色填充，在 Section 中剖到的画黑色粗线、未剖到的画浅灰虚线。
- 分类结果可以保存为"图层映射模板"，按公司或项目复用。系统会按图层名关键词自动预填，如 `Tree`、`Road`、`MULLION` 对应 `Ignore`，`slab` 对应 `Ignore` 并作为楼层校核参考。

### A2 Program 体块与命名
- 每个 program 一个**闭合体块**（Brep、Extrusion 或闭合 Mesh），一般一层一块；跨层空间（Auditorium、挑空）建成一块即可。
- **图层** = program 类别，如 `PRG::Lab`、`PRG::Office`；**对象名称** = 图上的标签，如 `TYPICAL LAB FLOOR`。
- 特殊类别：`PRG::Core`（核心筒）、`PRG::Void`（挑空，用虚线表示）、`PRG::Shell`（白底黑框）、`PRG::Circ-Vertical`（坡道、楼梯）。
- 支持图块（Block Instance）：插件会展开嵌套的变换来读取几何。
- 多方案：每个方案放在一个顶层图层下（如 `OPT-1`、`OPT-2`），导出时分别输出。

## 3. B — 系统生成，用户确认

面板按 Tab 顺序排列，每一页都有"确认"勾选。全部确认后，导出按钮才会亮起。

| Tab | 系统自动做的 | 用户确认或修改的 |
|---|---|---|
| ① 图层分类 | 按关键词预填 A1 中的角色 | 角色和风格模式 |
| ② 楼层 | 取 program 体块的**底面标高**，按容差聚类生成楼层线（见 B1） | 层名、标高、是否为夹层、是否合并 |
| ③ 名称 | 读取对象名称；没有名称时用 program 名；按名称加楼层生成唯一 ID | 逐行修改名称，可批量替换 |
| ④ 配色方案 | 默认用公司图例；也可以导入项目自己的方案（JSON 或 Excel） | 每个 program 对应的颜色、显示名，以及排序（决定图例和饼图的顺序） |
| ⑤ 剖切 | 读取 `SEC::*` 图层上的线；没有就提示用户拾取 | 剖切线、看向方向、可见进深 |
| ⑥ 输出 | 默认路径：`<3dm所在文件夹>/_Diagrams/<项目名>_<方案>_<日期>/` | 输出路径；勾选要输出哪些图；比例；画板尺寸（默认 11×17 横向） |
| ⑦ 检查 | 列出所有不确定项，点击可在视口中定位 | 逐项处理，或标记为忽略 |

### B1 楼层线生成（处理夹层）
1. 收集所有 program 体块的底面标高，按容差（默认 1'-0"）聚类。
2. 聚类结果中，间距 ≥ 最小层高（默认 10'-0"）的是**主楼层**，按顺序命名为 `B1`、`L1`、`L2` …（地面标高可以设置）。
3. 落在两个主楼层之间、离下层不到最小层高的，标为**夹层候选**（如 `L2M`）。用户选择：
   - 作为独立的一层，在爆炸轴测里单独拉开；
   - 或者并入下层。
4. 可选校核：如果有 `slab` 一类的图层，系统比对楼板标高和聚类结果，不一致时提示。
5. 在 Rhino 视口里用半透明平面和标签显示楼层线，在表格里修改后实时刷新。

### B2 不确定项（第 ⑦ 页）
- 体块未闭合
- 体块之间有体积重叠
- 体块所在图层未分类
- 体块没有名称（将使用默认名）
- 夹层没有确认
- 剖切线没有穿过任何体块
- 一个 program 在配色方案中没有对应颜色

## 4. C — 系统自动添加：配景人物

- **素材**：使用公司的配景库 `entourage.ai`，其中包含剖立面人物剪影和平面顶视人物，作为 Symbol 放置。插件自带一套默认素材，可以替换。
- **分布规则**：
  - 泊松盘随机分布，保证最小间距，不会挤在一起；
  - 按 program 设置密度，例如：Lobby、Dining 等公共空间密度高；Lab、Office 中等；Mechanical、Shell、Core 为 0；
  - 室外：Plan 中放在 `BG·Hardscape` 上，Section 中放在地坪线上，Axon 中放在场地上。
- **尺寸和姿态**：按真实身高（约 5'-9"）缩放；随机挑选不同造型，随机左右镜像。Section 中人物站在楼板线上，不会穿进下一层。
- **图层**：每个 .ai 中独立一个 `ENTOURAGE` 图层。
- **随机种子**：种子保存在项目设置中，重新导出时位置不变；面板上有"重新随机"按钮。

## 5. D — 成果与样式规范

### 5.0 输出文件夹
```
_Diagrams/<Project>_<Option>_<yyyymmdd>/
  01_Plans.ai               每层一个画板，另加一个总排版画板（B1 / L1 / … / TOWER 网格）
  02_Section_A.ai           每条剖切线一个文件
  02_Section_B.ai
  03_Axon_Stacked.ai        叠合式
  04_Axon_Exploded.ai       爆炸式
  05_Program_Diagram.ai     Program 分类图
  06_Program_Pie.ai         饼图
  program_areas.csv         面积统计
  diagram.json              所有几何和设置，用于重新导出和排查问题
  export_log.txt            不确定项和警告
```
- 生成方式：插件写出一个总控 `.jsx` 脚本，然后**自动启动 Illustrator**（Windows 通过 COM，Mac 通过 `osascript`），依次生成并保存所有 .ai。如果 Illustrator 没有安装，只输出 `.jsx` 和 SVG，用户可以之后手动运行。
- 重新导出时，按对象名原位更新生成的图层；`_MANUAL` 和 `OVERLAY` 图层永不覆盖。

### 5.2 Plan（参考：Research Building Level 1，以及 Downtown Concept Plans）
- 每层在"标高 + 4'-0""处水平剖切，得到 program 色块。
- 建筑外轮廓用 2.5 pt 黑线；体块之间的分隔线用 0.5 pt。
- 标签放在色块内最宽处，按长边方向旋转。放不下时改用引线，标在色块外面。
- 核心筒用 `#999999`；Void 用虚线加对角交叉线。
- 背景按 A1 的设置：街区、道路、绿地、树、用地红线。
- 版面：
  - 单层画板：左上角是层名（如 `Level 1`）；左下角是图例（3 列，色块 + 名称，只列出本层出现的 program）；右下角是比例尺和指北针。
  - 总排版画板：网格排列，可设置列数；每张图左上角标粗体层名（`B1`、`L1` … `TOWER`）。

### 5.3 Section（参考：Research Building Section A/B，以及 Downtown Concept Sections）
- **剖到的部分**：每个 program 的截面画成**圆角色条**。
  - 上下各内缩 0.12 × 层高，圆角 6 pt，色条之间留 1.5 pt 白缝；
  - 标签居中，长名称自动换行；
  - 剖到的建筑外轮廓用 2.5 pt 黑线。
- **楼板线**：每层画通长的双细线，比体块两端各长出 2'-0"。
- **未剖到的部分**（可见进深以内）：本项目体块和 `BG·Building` 只画投影外轮廓和楼层线，用浅灰虚线，不填色；建筑名标在顶部。核心筒投影画成虚线竖线。
- **地坪**：地坪带 `#E5E5E5`，地下部分画基坑轮廓。
- **注释**：
  - 街道名放在地坪下方；
  - 用地红线用红色点划线，竖排标注 `PROPERTY LINE`；
  - 建筑总高度用斜杠端点标注；
  - 可选：左侧的层高标注列（如 `L1 16'-6"`）、右上角的 key plan（由插件生成一张小平面并标出剖切线）。
- 坡道和楼梯（`PRG::Circ-Vertical`）画成斜线或楼梯纹样。
- 配景：人物和背景中的树。

### 5.4 Axon（参考：Atlanta 爆炸轴测，以及 Research Building 体量轴测）
- **公共设置**：
  - 投影：等轴测；也可以使用当前视口的平行视图角度；
  - 消隐：先按深度排序；有复杂遮挡时自动退回 Make2D。
- **叠合式**：
  - 完整体块，外轮廓 2.5 pt，内部棱线 0.5 pt；
  - program 颜色铺在顶面和侧面，侧面加深 10%，体现明暗；
  - 场地用绿色底，街道用灰色粗箭头加白字。
- **爆炸式**：
  - 每层沿 z 方向拉开（默认 1.5 × 层高），楼板为白色，厚度可设，外轮廓用黑色粗线；
  - program 色块铺在楼板顶面；标签用仿射变换贴在平面上，文字仍然可编辑；核心筒用灰色，标 `CORE`；
  - 右侧一列 Level 标签，用细引线连到各层楼板；
  - 可选：竖向连接体（如中庭、楼梯）画成浅色半透明体块；流线留空，在 `OVERLAY` 中手画；
  - 背景：底层显示场地、街区和道路。

### 5.5 Program 分类图（参考：Detailed Program Proposal）
- **数据源**（二选一）：
  1. **Excel 程序表**（推荐）。插件提供模板，列为：Department、Sub-group、Code、Room Name、Program Category、Qty、ASF/each、Multiplier（如 ×6 层）；
  2. 没有 Excel 时，用模型体块：每个体块画一个矩形。
- **版式**：
  - 每个 Department 是一个灰色虚线框（0.75 pt，线段 6 / 间隔 6）；
  - 框外左上角是标题，粗体大写，如 `RESEARCH LABS (X6)`；
  - 框内按 Sub-group 分组，组标题用常规字重，如 `Typical Floor Collaboration`；
  - 每类房间：上方是小号文字 `1.3.3 Reservable Benching`，下方是 Qty 个**按面积等比例**的矩形，排成一行，间隔 1 pt 白缝，颜色取 Program Category；
  - 框内右下角是合计，大字号，如 `108,024 ASF`。
- **排版**：自动打包（shelf packing）。Department 框的位置可以在面板中拖动排序。

### 5.6 饼图（参考：PROGRAM SF）
- 环形图，内径约为外径的 43%；从 12 点方向开始顺时针排列；顺序与配色方案的排序一致。
- 中心文字为粗体 `PROGRAM SF`；右侧图例上方是粗体 `TOTAL:` 和合计值，下面每行是"方块色标 + `Office 12,813 SF`"。
- 数据源可选：模型面积（GSF，按楼层剖切面积计）或 Excel（ASF），在面板中切换。
- 可选输出：横向堆叠条形图（参考 Program Development Summary 的样式）。

## 6. 技术方案
| 模块 | 实现 |
|---|---|
| 插件 | C#（.NET 7 + RhinoCommon），Eto 面板，Windows 和 Mac 都支持，通过 Yak 分发 |

| Excel | 用 ClosedXML 读取 .xlsx 程序表 |

## 7. 示例模型检查结果（`20251222-2100M-RENZO.3dm`）
我用 rhino3dm 读了这个模型，结论如下：
- **单位**：英尺。共 3479 个对象、51 个图层。
- **模型内容**：主要是**立面和幕墙的设计模型**，有竖梃、玻璃、楼板、柱、树、种植池和导入的网格。**没有 program 体块**，所有图层颜色都是黑色。
  - 这说明 A1（背景和图层分类）与 A2（建 program 体块）是必需的步骤；
  - 也说明关键词预填 `Ignore` 很有价值：`MULLION`、`CW-*`、`Glass`、`NOT USED` 等图层可以直接排除。
- **图块**：有 340 多个图块实例，还有 V-Ray 剪切平面和隐藏图层。插件需要展开图块，并忽略隐藏图层和渲染辅助对象。
- **楼层**：幕墙图层的底标高是 0.5、17.0、29.5、42.0 … 129.5 ft，与之前那张 2100 M St 剖面（L1 16'-6"，标准层 12'-6"）吻合。可以用它来验证 B1 的楼层聚类和楼板校核。
- **还需要**：同一个项目**建好 program 体块并命名**的版本，作为端到端的测试样本。
