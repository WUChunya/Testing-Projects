v1.0 · 2026-10-13 · 状态：S0–S6 完成，插件 v0.8.0，待 Windows 验收（修订过程见 `docs/CHANGELOG.md`；使用说明 `docs/USER_GUIDE.md`，建模约定 `docs/MODELING_CONVENTION.md`）

**v1.0 主要变化（用户 rev 0.8，Downtown 模型 2026-10-13 版）**
- 文字：全部 **Futura PT、全大写**；粗体位置用 FuturaPT-Heavy，其余 FuturaPT-Book（未安装时退回 Arial）。
- 新图层角色：`NC.Interior`（平面中灰线）、`NC.Furniture`（平面浅灰线）、`NC.Massing`（建筑外轮廓，含无 program 的空间，虚线）、`NC.Screen`（围墙 / 装饰墙等表皮，只画一层面，不挤出体块）。配景人物和树用公司 ENTOURAGES.ai / TREES.ai。
- 总平面范围：NC 场地四周各留场地自身尺寸的 5 倍（`plan.siteExtentFactor`）。
- 平面：不同硬质铺装交界 1 pt、场地与道路交界 1.5 pt 深灰浅描边；新增 "LEGEND & SYMBOLS" 画板保存全部图例和符号；`LEVEL X` 无底色、字号同最大 program 名；同层体块间 < 0.2 ft 视为贴合（`cleanup.sealGapFt`），白色细线分隔、外轮廓统一。
- 剖面：人物随机分布并避开文字；program 名在色块正中，每块都写，放不下用前三个字母，再放不下不写；顶层只有 Shell / Core / 设备时画成一个灰色 PENTHOUSE 色块，上方不加楼板，加 T.O. PENTHOUSE 标高。
- 场地轴测：不画楼板，体块逐层从楼板到楼板拉伸，层间 2 pt 黑线（单独图层 `AXON_LEVEL_LINE`），粗线只描建筑外轮廓。
- 爆炸 / 分层轴测：场地放在地面层（L1），地下层在挖开的场地下方；分层轴测的地下层场地只用虚线暗示，并画挖方的实墙；树被楼板遮挡；穿出屋面的核心筒按真实体量（体块在相邻体块顶 / 底处分段消隐）。
- 立面：标高线与剖面完全一致，虚线贯穿整个画面。

**v0.9 主要变化（依据 Downtown 模型试用反馈）**

## 1. 总体流程

| 阶段 | 谁来做 | 内容 |
|---|---|---|
| **A 用户输入** | 用户 | ① 指定哪些图层是背景，以及用什么风格画；② 做好 program 体块并命名 |
| **B 系统生成，用户确认** | 系统 → 用户 | 房间 / 体块 / 图层名称、配色方案、楼层线、剖切线、输出路径 |
| **C 系统自动添加** | 系统 | 配景人物：随机分布，放在独立图层 |
| **D 成果** | 系统 | Plan、Section、Axon（叠合式 / 爆炸式）、Program 分类图、饼图，都是 .ai，输出到同一文件夹 |

插件形态：
- 正式的 Rhino 8 插件（.rhp），**只支持 Windows**，通过 Yak / Package Manager 安装；
- 带工具栏，主命令是 `ProgramDiagram`，配一个可停靠的侧边面板；
- 所有设置保存在 3dm 文件里，下次打开不用重新配置。

## 2. A — 用户输入

### A1 背景分类与风格
面板第 1 页"图层分类"列出模型中所有**有对象的图层**（隐藏图层默认不勾选）。用户为每个图层指定一个角色：

角色分两组：**NC（New Construction，本项目新建）**和 **BG（Background，现状背景）**。场地类角色（树、水、绿地、硬质）两组都有；图层路径中含 `NC::` / `NEW::` / `PROJECT::` / `PROPOSED::` 时自动归入 NC。

| 角色 | 组 | 举例 / 用途 |
|---|---|---|
| `Program` | NC | 由插件读取的 program 体块（见 A2） |
| `NC.Core` | NC | 核心筒：作为 program `CORE` 的体块，计入面积；爆炸轴测中连接上下层 |
| `NC.Stair` | NC | 楼梯、电梯、交通：program `STAIR`；爆炸轴测 A 为连接体、B 为竖向粗线 |
| `NC.Slab` | NC | 楼板：校核楼层，剖面 / 立面中的楼板（原 `BG·Slab`） |
| `NC.Facade` | NC | 立面：玻璃、竖梃、遮阳等（原 `BG·Facade`，见 A3） |
| `NC.Structure` | NC | 柱、墙、梁：平面中剖到画深灰实心，看线中单独成层 |
| `NC.Green` | NC | 本项目绿地：屋顶花园、露台种植、场地草坪 |
| `NC.Hardscape` | NC | 本项目广场、铺装 |
| `NC.Tree` / `NC.Water` | NC | 本项目的树、水景 |
| `NC.Interior` | NC | 室内隔墙：平面中按剖切高度画中灰线（实体剖切，曲线照画） |
| `NC.Furniture` | NC | 家具：平面中画浅灰线（剖切高度以下的顶视轮廓） |
| `NC.Massing` | NC | 建筑外轮廓体量（含无 program 的空间）：平面、剖面画虚线，轴测画虚线外轮廓；不计面积 |
| `NC.Screen` | NC | 围墙、装饰墙、格栅等表皮：只画这一层面（平面一条线、剖面剖切线、轴测薄片），不挤出体块 |
| `BG.Building` | BG | 周边建筑 |
| `BG.Road` / `BG.Hardscape` / `BG.Landscape` / `BG.Tree` / `BG.Water` | BG | 道路、街区与人行道、绿地、树、水体 |
| `BG.Base` | BG | 场地底板、图框底座：地坪参考，不参与剖切 |
| `BG.Line` | BG | 用地红线、轴网等线性要素 |
| `Ignore` | 幕墙、竖梃、材质、渲染辅助等 |

每个背景角色选一种**风格模式**，默认值来自公司配色方案：

| 模式 | 效果 |
|---|---|
| **黑白灰** | 灰度填色，加细黑或深灰轮廓 |
| **线型** | 不填色，只画轮廓；可选实线或虚线，可设线宽 |
| **彩色** | 使用公司配色，如绿地 `#D7DEBC`、树 `#C8E2BF` 加深绿轮廓 |

- 同一个角色在不同的图里可以用不同的模式。例如 `BG·Building` 在 Plan 中是灰色填充，在 Section 中剖到的画黑色粗线、未剖到的画浅灰虚线。
- 分类结果可以保存为"图层映射模板"，按公司或项目复用。系统按图层名关键词自动预填，例如：
  - `Tree` → `BG·Tree`，`Road` → `BG·Road`
  - `GLASS`、`CW-*`、`MULLION` → `NC.Facade`；`slab` → `NC.Slab`
  - `CORE` → `NC.Core`；`STAIR`、`ELEVATOR`、`SHAFT` → `NC.Stair`；`COLUMN`、`STRUCT` → `NC.Structure`；`GREEN ROOF`、`TERRACE` → `NC.Green`
  - 每个角色在各图中的画法见 `styles/style_default.json › roles`（plan / axon / view）
  - `CONTEXT` → `BG·Building`，`SITE` → `BG·Hardscape`，`FRAME` → `BG·Base`
- **子图层单独判断角色，不继承父图层。** 测试模型中 `BACKGROUND FRAME::GLASS` 实际是立面玻璃，而它的父图层是场地底板。
- 可以选择"使用 Rhino 图层颜色"作为彩色模式的颜色来源。测试模型中 `CONTEXT BUILDINGS` 已设为 `#E6E6E6`。

### A2 Program 体块与命名

- 每个 program 一个**闭合体块**（Brep、Extrusion 或闭合 Mesh），一般一层一块；跨层空间（Auditorium、挑空）建成一块即可。
- **图层** = program 类别。推荐命名为 `PRG::Lab`，也接受直接命名，如 `LAB`、`OFFICE`、`LOBBY`（测试模型就是这种写法）。系统按名称模糊匹配公司图例，再由用户确认。
- **对象名称** = 图上的标签，如 `TYPICAL LAB FLOOR`。不写对象名时，默认用 program 名（测试模型中所有对象都没有名称）。
- **体块不要求完美**：可以是非封闭的、跨很多层的、彼此重叠的，由第 3.5 节的几何清洗处理，并交给用户确认。
- 特殊类别：`PRG::Core`（核心筒）、`PRG::Void`（挑空，用虚线表示）、`PRG::Shell`（白底黑框）、`PRG::Circ-Vertical`（坡道、楼梯）。
- 支持图块（Block Instance）：插件会展开嵌套的变换来读取几何。
- 多方案：每个方案放在一个顶层图层下（如 `OPT-1`、`OPT-2`），导出时分别输出。

### A3 立面（Facade）
立面和 program 体块、楼板分开建模，是常见情况。立面属于设计内容，**必须保留**，作为背景输出。
- **识别**：满足以下特征的图层或对象，标为"立面候选"，由用户在第 ① 页确认：
  - 图层名包含 GLASS、CW、MULLION、FIN、PANEL、FACADE 之一；
  - 或者是薄片，且贴在建筑外轮廓上，并按楼层重复出现。
- **每张图中的画法**（可在面板中修改）：

  | 图 | 默认画法 | 其他选项 |
  |---|---|---|
  | Plan | 在外轮廓线外侧画一条 0.35 pt 细线，表示玻璃 | 隐藏 |
  | Section | 剖到的立面画 0.5 pt 线；未剖到的立面分格画浅灰细线 | 隐藏 |
  | Axon 叠合式 | 半透明白色罩面，透明度 30%，加分格细线，program 颜色透出来（类似 Exterior View 的效果） | 只画轮廓 / 隐藏 |
  | Axon 爆炸式 | 隐藏 | 只画轮廓 |

- 立面在每个 .ai 文件中都放在独立的 `FACADE` 图层，可以一键开关。

## 3. B — 系统生成，用户确认

面板按 Tab 顺序排列，每一页都有"确认"勾选。全部确认后，导出按钮才会亮起。

| Tab | 系统自动做的 | 用户确认或修改的 |
|---|---|---|
| ① 图层分类 | 按关键词预填 A1 中的角色 | 角色和风格模式 |
| ② 几何清洗 | 封口、切分跨层体块、解决重叠、移除游离对象（见第 3.5 节） | 修复结果、优先级、是否保留跨层空间 |
| ③ 楼层 | 由楼板、体块底面、立面面板三个来源综合判定（见 B1） | 层名、标高、是否为夹层、是否合并 |
| ④ 名称 | 读取对象名称；没有名称时用 program 名；按名称加楼层生成唯一 ID（`L03_LAB_01`） | 逐行修改名称，可批量替换；可**单独改某个体块的 program**（覆盖图层设置） |
| ⑤ 配色方案 | 默认用公司图例；也可以导入项目自己的方案（JSON 或 Excel）；可**添加自定义 program**（自动生成 Key 和颜色，别名用于自动预填），新 program 立即出现在 ① 和 ④ 的下拉中 | 每个 program 对应的颜色、显示名、别名，以及排序（决定图例和饼图的顺序） |
| ⑥ Sections 剖切 | 读取 `SEC::*` 图层上的线；没有就提示用户拾取 | 看向方向、可见进深；是否穿过体块 |
| ⑦ Elevations 立面 | 读取 `ELEV::*` 图层上的线；没有就提示用户拾取（与剖切分开管理） | 看向方向、可见进深 |
| ⑧ 输出 | 保存位置默认 = 3dm 所在文件夹；每次导出新建 `YYYY MMDD_Conceptual Program Diagram_HHMMSS` 子文件夹 | 保存位置；勾选要输出哪些图；**比例（自由输入 + 预设）**；画板（默认 Fit content）；是否同时导出 PNG；是否后台生成 .ai；轴测是否用当前视口角度 |
| ⑨ 检查 | 列出所有不确定项，点击可在视口中定位 | 逐项处理，或标记为忽略 |

### B1 楼层线生成（三个来源综合判定，并处理夹层）
1. **收集候选标高**，三个来源按权重从高到低：
   - **楼板顶面**：只取 `BG·Slab` 中的**水平板**（厚度小于 3'，面积大于 200 SF）。同一图层里的柱、肋、线段会被过滤掉。测试模型的 slab 图层共 231 个对象，其中只有 17 块水平板。
   - **program 体块底面**：经过第 3.5 节清洗之后的体块。
   - **立面面板底边**：按楼层重复出现的标高。
2. **聚类**：容差默认 1'-6"。体块底面通常比楼板顶面高几英寸（测试模型中是 4"），所以统一吸附到下方最近的楼板顶面。
3. **命名**：间距 ≥ 最小层高（默认 10'-0"）的是**主楼层**，按顺序命名为 `B1`、`L1`、`L2` …；地面标高默认取 L1，可以修改。
4. **夹层候选**：落在两个主楼层之间、离下层不到最小层高的标高，标为夹层候选（如 `L2M`）。用户选择：
   - 作为独立的一层，在爆炸轴测里单独拉开；
   - 或者并入下层。
5. **离群项**：只有一个来源支持的标高、或者与楼板标高差得太多的标高，列入不确定项。
6. **预览**：在 Rhino 视口里用半透明平面和标签显示楼层线，并标明每条线来自哪些来源；在表格里修改后实时刷新。

### B2 不确定项（第 ⑨ 页）
- 体块未闭合，且无法自动封口
- 单张曲面被放在 program 图层（不是体块）
- 体块之间有重叠，且尚未确认优先级
- 立面候选尚未确认
- 远离建筑主体的游离对象
- 体块所在图层未分类
- 体块没有名称（将使用默认名）
- 夹层没有确认
- 剖切线没有穿过任何体块
- 一个 program 在配色方案中没有对应颜色

### 3.5 几何清洗（第 ② 页）
所有自动处理都会在视口中高亮，并留下记录，用户可以逐项撤销。

| 情况 | 自动处理 | 用户确认 |
|---|---|---|
| **单位** | 读取模型单位（mm、ft 都支持）。内部统一换算，输出按项目设置用英制或公制标注 | 输出单位 |
| **远离原点的坐标** | 计算时平移到建筑主体包围盒的角点，避免精度问题和 AI 画布越界。测试模型的坐标约在 (−13,600 ft, 11,400 ft) | — |
| **游离对象** | 离主体包围盒很远的对象直接排除。测试模型中 slab 图层有一个 Mesh 在原点附近，距离主体约 4 km | 是否排除 |
| **非封闭体块** | ① 先尝试平面封口（CapPlanarHoles）；② 封不上时，按剖切线连接，在容差内闭合；③ 仍失败就列为不确定项 | 修复结果 |
| **单张曲面** | 不当作体块。可选：忽略 / 当作立面涂色并入 `BG·Facade` / 按指定进深挤出成体块 | 选择处理方式 |
| **跨层体块** | 跨 2 层且高度 ≤ 1.6 倍层高：默认保留为**通高空间**（如两层高大堂）。跨 3 层及以上：默认**按楼层线切分**成每层一块，名字不变 | 每块单独选择：保留或切分 |
| **体块重叠** | 默认规则是**更具体的优先**：体积小的体块覆盖体积大的。例如单层的 OFFICE 覆盖多层的 LAB 大体块。也可以改为按图层优先级排序。面积统计在解决重叠之后计算，不会重复计入 | 逐个冲突确认，或批量应用规则 |
| **地下的背景建筑** | 背景建筑在地坪以下的部分自动截掉（测试模型中最低到 −170 ft） | 地坪标高 |

- **随机种子**：种子保存在项目设置中，重新导出时位置不变；面板上有"重新随机"按钮。

### 5.4 Axon（参考：Atlanta 爆炸轴测，以及 Research Building 体量轴测）
- **v0.9**：
  - 新增 `03_Site_Axon.ai`（SITE_STYLE §1，参考图 Question 4）：本楼体量（楼层线、program 色）+ 周边建筑白色体块（真实高度，最高 `axon.site.maxContextHeightFt`）+ 场地（街区、道路、绿地、本项目广场）+ 棒棒糖树 + 人（只在本项目广场及周边）；屋顶写建筑名称；`ANNOTATION` 图层留空给人行流线、视线、卸货图标，插件永不清空。

- **公共设置**：
  - 投影：等轴测；也可以使用当前视口的平行视图角度；
  - 消隐：先按深度排序；有复杂遮挡时自动退回 Make2D。
- **叠合式**：
  - 完整体块，外轮廓 2.5 pt，内部棱线 0.5 pt；
  - program 颜色铺在顶面和侧面，侧面加深 10%，体现明暗；
  - 场地用绿色底，街道用灰色粗箭头加白字。
- **爆炸式**：
  - 每层沿 z 方向拉开（默认 1.5 × 层高），楼板为白色，厚度可设，外轮廓用黑色粗线；
  - program 色块铺在楼板顶面；标签用仿射变换贴在平面上，文字仍然可编辑；核心筒用灰色，标 `CORE`；
  - 右侧一列 Level 标签，用细引线连到各层楼板；
  - 可选：竖向连接体（如中庭、楼梯）画成浅色半透明体块；流线留空，在 `OVERLAY` 中手画；

## 9. 待确认

已采用的默认值（用户未提出异议）：重叠"体积小的优先"；跨层"2 层且 ≤1.6 倍层高保留通高，否则切分"；单张曲面由用户在 ② 页选择（试用中选了"当作立面"）；标签字体 Century Gothic（粗体）。

原始问题：
1. **重叠规则**：默认"体积小的覆盖体积大的"，是否符合团队习惯？还是希望按图层顺序决定？
