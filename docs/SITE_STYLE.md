数值在 `styles/site_style.json`；参考图由 `tools/site_style_reference.py` 生成：
- `docs/reference/site_axon_reference.svg`（参考图 3：场地 program 轴测）

与 `docs/AXON_STYLE.md`（爆炸轴测 A，Atlanta 风格）共用：比例、ARCH D 画板、文档设置、SSR 斜向文字方法、图层命名规则。

## 0. 取值方法
- 颜色：从参考图逐区域取像素众数（按色相分组，去掉抗锯齿过渡色）。
- 尺寸：**参考图宽度 = 图纸宽度**。参考图 3/4/5 宽 1666 px，ARCH D 宽 2592 pt，所以 **1 px = 1.556 pt**（参考图 1 宽 2000 px，1 px = 1.296 pt，与 AXON_STYLE 的「11×17 × 2.118」一致）。
- 字号 = 实测大写字高 ÷ 字体大写字高比例（Arial 0.716）× 1.556。
- 字体按字形判断：图 3/5 为 Arial（Helvetica 类），图 4 的场地标注为 Gotham Book（几何无衬线；没有 Gotham 时用 Montserrat）。

## 3. 爆炸轴测 B（参考图 5 右）
与爆炸轴测 A（Atlanta）的区别：

| 项目 | A（AXON_STYLE.md） | B（本节） |
|---|---|---|
| 投影 | 等轴测 30°/30° | **平面斜轴测 30°/60°**（平面不变形，平面 Y 向右上 30°，X 向右下 60°） |
| 楼板 | 整块楼板 + program 铺在顶面 | **每个 program 单独成块**，厚 6 ft，不透明度 85%，侧面加深 15% / 30%，0.75 pt 白色棱线，无黑色外轮廓 |
| 层间距 | 顶面露出 ≥ 70% | 层间距 = 0.75 × 平面投影深度（上下层几乎不遮挡）；6 层在 1"=45' 下需要 **ARCH D 竖版 24×36** |
| 标签 | Myriad Pro Semibold 20/16 pt，白色 70%，前角对齐 | **Arial Bold 26 / 13 pt，白色 90%，居中**，沿长边，贴在平面上 |
| 层标 | 方块 #FBBC10 + 「Level 7」 | 方块 14 pt #E49C30 + **「LEVEL 6」Arial Bold 17 pt 全大写** #333333；引线 0.75 pt #666666，从楼板最右点向右下 |
| 中庭 / 流线 | 米色半透明体 | 浅黄平板 #F6F6C6 60%（各层），中庭边界竖线 0.75 pt #E0E0B0 |
| 竖向核心 / 楼梯 | — | 3.0 pt #E4BA3C 竖线，贯穿各层 |
| 场地 | 底层显示环境 | 首层放一块白色场地板（1.0 pt #9A9A9A 外框），上面以 55% 不透明度印出总平面（第 2 节的样式）；街道名 Arial Bold 19 pt #6C6C6C，贴平面 |
| 地下室 | — | 放在场地板下方一个层间距处，同样的块体样式（参考图为动物房 #846C54） |

参考图 5 实测颜色（偏灰、偏暗，是半透明叠在白底上的效果）：办公 #848A78、教室 #BAC6A8、实验室 #F0C684、实验室外圈 #9CB4C0、模拟 #DECCD8、聚集 #EAD278、中庭 #F6F6C6、建筑支持 #AEA8A2、动物房 #846C54。实际出图用公司图例颜色，再加 85% 不透明度，就能得到相同的灰度感。

## 4. 三种图共用的规则
- 图层（自上而下）：`OVERLAY` · `_MANUAL` · `ANNOTATION`（流线、视线、图标）· `LABEL` · `PROJECT` · `TREE` · `CONTEXT` · `LANDSCAPE` · `GROUND`。插件永不改动 `OVERLAY` / `_MANUAL`。
- 图标（人形、眼睛、卡车）做成 AI **符号**，颜色用全局色板，便于统一替换。
- 流线虚线做成图形样式 `PD_PedFlow` / `PD_View`，箭头用描边箭头而不是单独的三角形，修改路径时箭头跟着走。
