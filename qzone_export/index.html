QQ空间说说导出

导出某个QQ号的全部说说，按时间从早到晚排好，存成一个可以直接用 Chrome 打开的网页。

1登录并打开对方的QQ空间

在 Chrome 里登录QQ空间，打开对方的空间页面：user.qzone.qq.com/350904191，确认能看到说说。

2复制导出代码

3在对方空间页面运行

回到对方的QQ空间页面，按 F12（Mac 为 ⌥+⌘+J），切到 Console（控制台），粘贴代码后按回车。

如果 Chrome 提示不能粘贴（Warning: Don't paste code…），先在控制台输入 allow pasting 回车，再粘贴一次。

确认QQ号后，页面右上角会显示读取进度。

4打开下载的文件

完成后浏览器会自动下载 qzone_QQ号_日期.html，双击就能在 Chrome 里阅读：按年份分组，可以搜索，可以切换正序和倒序。

只能导出你的账号本来就有权限看到的说说。数据只在你自己的浏览器里处理，不会上传到任何地方。导出的网页里，图片仍从QQ的服务器加载。

想用书签一键运行？

把下面的按钮拖到书签栏（Ctrl+Shift+B 显示书签栏）。以后在对方空间页面上直接左键点击这个书签即可。

如果出现 about:blank#blocked，说明 Chrome 拦截了书签：不要在新标签页里点它，也不要用中键或右键“在新标签页中打开”。如果仍被拦截，用上面的控制台方法。
